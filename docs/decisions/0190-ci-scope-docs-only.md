# 0190. CI 실행 범위: main push는 늘 전체, PR은 바꾼 파일이 모두 docs/ 아래면 하네스만

- 상태: 채택
- 날짜: 2026-11-28
- 결정한 사람: 사람(Issue #67 '아직 정하지 않은 정책' 1번. 이 Issue 세션에서 선택지 셋을 묻고, 사람이 추천인 '하네스만'을 골랐다)
- 관련: Issue [#67](https://github.com/Rasit-NP/curtain-call/issues/67), 결정 [0001](0001-verify-single-entry.md), [0183](0183-github-actions.md),
  [0193](0193-ci-workflow-impl.md)(구현)

## 결정

- main push는 늘 `verify.sh` 전체를 실행한다(결정 0183, Issue #67 '이미 정한 정책').
- PR은 PR이 바꾼 파일이 모두 `docs/` 아래면 `verify.sh harness`만 실행하고, 하나라도 밖에 있으면 전체를 실행한다.
- 어느 쪽이든 같은 잡(`verify`)이 돌아 결과를 남긴다. 실행을 건너뛰지 않으므로, 이 잡을 필수 검사로 걸어도 '대기'로 남지 않는다.

## 근거

- 하네스가 결정·진행 기록 목차를 검사하므로, 문서만 바꾼 PR에서도 목차가 어긋나면 잡힌다.
- `docs/` 아래 파일을 읽는 테스트는 없다. `docs/` 밖의 문서는 문서로 치지 않는다. 루트 `CLAUDE.md`는 백엔드 `ErrorCodeTest`와 프론트엔드 `errorMessages.test.ts`가 오류 코드 표를 읽는다.
- 요금제: 사람이 "Free입니다만, 이후에 public으로 공개해야 하기 때문에, 요금제는 크게 걱정하지 않아도 될 듯 합니다"라고 답했다.
  물을 때는 비공개라 월 2,000분(리눅스 러너)이었다. 사람이 2026-11-28 이 Issue 진행 중에 저장소를 공개로 바꿔, 이제 표준 러너 실행 시간은 무료다.
- 로드맵 1의 PR 25개 중 `docs/`만 바꾼 PR은 2개(#40, #49)라 지금 아끼는 시간은 크지 않다. 진행 기록·결정 기록만 고치는 PR이 늘어나는 마무리 단계에서 효과가 있다.

## 고려했지만 고르지 않은 것

물을 때 보인 선택지다.

- 늘 전체: 가장 단순하지만 문서만 바꾼 PR도 전체 검증 시간을 쓴다.
- 문서 PR은 건너뛰기(잡은 돌고 검증 없이 통과): 목차 검사도 빠진다.

## 적용과 남은 점

- 판단은 `scripts/ci-scope.sh`가 한다. 세부(바뀐 파일을 정하는 방법, 알 수 없을 때)는 결정 [0193](0193-ci-workflow-impl.md)이다.
- `docs/` 아래 파일을 읽는 테스트를 만들면 이 규칙을 고친다.
- 실행 시간은 진행 기록(#67)에 적는다. 공개 저장소라 월 한도는 없지만, 문서만 바꾼 PR을 빨리 끝내는 효과는 그대로다.
