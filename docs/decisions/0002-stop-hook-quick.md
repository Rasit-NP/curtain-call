# 0002. 작업을 끝낼 때 Stop 훅으로 quick 검증, 같은 턴에 한 번만 막기

- 상태: 채택
- 날짜: 2026-11-26
- 결정한 사람: 에이전트 제안, 사람 병합
- 관련: Issue [#1](https://github.com/Rasit-NP/curtain-call/issues/1), PR [#2](https://github.com/Rasit-NP/curtain-call/pull/2)

## 결정

Claude Code Stop 훅이 작업을 끝낼 때마다 `verify.sh quick`을 실행한다. 실패하면 멈춤을 막고 결과를 에이전트에게 준다. 이미 훅 때문에 이어 가는 중(`stop_hook_active`)이면 다시 막지 않고 사용자에게 경고만 남긴다.

## 근거

- 에이전트가 검증을 잊고 끝내는 것을 사람이 매번 확인하지 않아도 되게 한다.
- 고칠 수 없는 실패로 매번 막으면 끝없이 반복된다. 한 번만 막고 그다음은 사람에게 넘긴다.

## 고려했지만 고르지 않은 것

- PR 전에만 검증: 작업 중 실패를 늦게 발견한다.
- 매번 막기: 무한 반복 위험.

## 적용과 남은 점

훅 timeout은 의존성 내려받기를 고려해 600초다. 백엔드·프론트엔드가 생기면 턴마다 수십 초가 걸릴 수 있다.
