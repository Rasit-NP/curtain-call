# 0009. 좌석에 지금 잡은 선점(holdId)을 둔다

- 상태: 에이전트 결정
- 날짜: 2026-11-26
- 결정한 사람: 에이전트(독립 리뷰), 사람 병합
- 관련: Issue [#3](https://github.com/Rasit-NP/curtain-call/issues/3), PR [#4](https://github.com/Rasit-NP/curtain-call/pull/4)

## 결정

`Seat.holdId`는 지금 이 좌석을 잡은 선점이고 `HELD`일 때만 있다. 좌석의 API 상태와 해제 범위는 이 값으로 판단한다.

## 근거

- 만료된 선점의 좌석을 새 선점이 덮어쓰면 한 좌석이 두 선점의 좌석 목록에 들어간다. 그때 어느 선점이 잡고 있는지 판정할 값이 없었다(독립 리뷰가 찾음).

## 고려했지만 고르지 않은 것

- 선점 쪽 목록만으로 판정: 만료 뒤 덮어쓴 경우를 구분할 수 없다.

## 적용과 남은 점

해제는 `holdId`가 이 선점인 좌석만 `AVAILABLE`로 되돌린다.
