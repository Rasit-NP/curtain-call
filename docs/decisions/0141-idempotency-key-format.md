# 0141. Idempotency-Key는 ASCII 출력 문자(0x21~0x7E) 1~100자이고 헤더는 하나여야 한다. 그 밖은 400 INVALID_INPUT

- 상태: 채택
- 날짜: 2026-11-28
- 결정한 사람: 사람(2026-11-28, Issue #55 세션. 에이전트가 낸 선택지 중 추천인 'ASCII 출력 문자만'과 '헤더가 두 번 이상이면 400'을 골랐다)
- 관련: Issue [#55](https://github.com/Rasit-NP/curtain-call/issues/55), 결정 [0006](0006-idempotency-record.md), [0072](0072-json-numbers-strict.md), [0090](0090-path-id-ascii-decimal.md), spec 6.7, 6.7.1

## 결정

결제 요청의 `Idempotency-Key`(spec 6.7 오류 표 2번)는:

- ASCII 출력 문자(0x21~0x7E)로만 된 1~100자다. 공백·탭·제어 문자·ASCII가 아닌 문자가 하나라도 있으면 `400 INVALID_INPUT`이다.
  그래서 명세의 '공백뿐'인 키도 400이고, 가운데에 공백이 있는 키(`a b`)도 400이다. 글자 수는 문자 수 = 바이트 수다.
- 헤더가 없거나 두 번 이상 오면(값이 같아도) `400 INVALID_INPUT`이다.

이 Issue에서 사람에게 물은 정책은 이 두 가지뿐이다.

## 근거

- 프론트엔드는 UUID(36자, `0-9a-f`와 `-`)만 보내므로 바뀌는 사용자가 없다.
- HTTP 헤더 값은 바이트열이다. 서버(Tomcat)는 ASCII 밖 바이트를 ISO-8859-1로 읽어, ASCII 밖 문자를 받으면 '100자'가 클라이언트의 인코딩에 따라 달라진다
  (한글 1자 = UTF-8 3바이트 = 서버가 읽은 3자). 유니코드 공백을 공백으로 보는 규칙도 실제 서버에서는 같은 이유로 판정되지 않는다.
- 경로 id를 ASCII 10진 표기만 받은 결정 0090, 본문 숫자를 JSON 숫자 그대로만 받은 결정 0072와 같은 방향이다.
- 헤더가 두 개면 어느 키로 처리할지 모호하다. 프레임워크 기본 해석에 맡기면 두 값이 쉼표로 이어진 키 하나가 될 수 있어, 클라이언트가 보낸 어느 키와도 다른 키로 처리된다.

## 고려했지만 고르지 않은 것

- 명세 문구 그대로(앞뒤 ASCII 공백·탭을 지워 비면 400, 길이는 문자 수, ASCII 밖 문자와 가운데 공백은 받음): 사람이 고르지 않았다.
  한글 키는 실제 서버에서 '100자'가 약 33자가 되고, MockMvc 테스트와 실제 서버의 글자 수가 다르다.
- 유니코드 공백까지 공백으로(`String.isBlank`), 길이는 코드 포인트: 사람이 고르지 않았다. 실제 서버에서는 판정되지 않는 규칙이다.
- 헤더가 여러 개면 첫 값을 씀: 사람이 고르지 않았다.

## 적용과 남은 점

- 코드: `payment.api.IdempotencyKeyHeader`(`read`, `parse`). 컨트롤러가 본문 검증 뒤에 부른다. 둘 다 오류 표 2번이라 어느 쪽이 먼저 걸려도 400이다.
- Spring Security 방화벽(`StrictHttpFirewall`)은 헤더 값을 읽는 순간 제어 문자가 든 값을 거부한다. 한글 키를 UTF-8로 보내면 서버가 읽은 문자열에
  C1 제어 문자(U+0082 등)가 생겨 여기에 걸리고, 처음에는 500 INTERNAL_ERROR가 됐다. 이 거부도 이 결정의 400으로 바꾼다(결정 [0142](0142-payment-impl.md), `docs/agent-log.md`).
- 실제 서버에서 확인한 것(임시 테스트, 지웠다): 앞뒤 공백·탭은 Tomcat이 지운 뒤 앱에 온다(`"   "` → 빈 값 → 400, `"  padded  "` → `padded`).
  DEL·0x01 같은 제어 바이트는 Tomcat이 먼저 400 INVALID_INPUT으로 거부한다(결정 0037의 밸브).
- spec 6.7 오류 표와 6.7.1에 이 규칙을 적었다. 키를 저장·재사용하는 것은 #56이다.
