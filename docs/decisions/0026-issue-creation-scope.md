# 0026. Issue 등록은 로드맵에서 지금 진행할 단계만, 더 필요하면 목록을 먼저 보여 주고 묻는다

- 상태: 제안(PR 병합 전)
- 날짜: 2026-11-26
- 결정한 사람: 사람(대화에서 지시)
- 관련: Issue [#29](https://github.com/Rasit-NP/curtain-call/issues/29), 로드맵 [#13](https://github.com/Rasit-NP/curtain-call/issues/13)

## 결정

Issue를 만들어 달라는 요청에는 로드맵(#13)에서 지금 진행할 단계의 Issue만 만든다. 그보다 많이 만들어야 할 것 같으면 만들 목록을 먼저 보여 주고 묻는다. 루트 `CLAUDE.md` '작업 흐름'의 'Issue 등록 범위'에 둔다.

## 근거

- "현재 진행해야 하는 작업을 이슈로 등록하라"는 요청에 에이전트가 로드맵의 남은 단계 전부(13개, #14~#26)를 만들었다. 사람이 지적해 모두 삭제하고 1단계만 #27·#28로 다시 만들었다.
- Issue는 지우면 번호를 다시 쓸 수 없다. 잘못 만든 Issue를 되돌리면 번호가 빈다(#14~#26).
- 저장소 규칙에 없으면 새 세션마다 같은 판단을 다시 한다. 에이전트의 개인 메모리는 그 컴퓨터의 에이전트 세션에만 적용되므로 규칙을 대신하지 못한다.

## 고려했지만 고르지 않은 것

- 에이전트 개인 메모리에만 남기기: 위 이유로 다른 세션과 컴퓨터에 적용되지 않는다.

## 적용과 남은 점

'지금 진행할 단계'는 로드맵 #13의 진행 상황으로 판단한다. 판단이 서지 않으면 목록을 보여 주고 묻는다. 지시 범위 규칙([0028](0028-instruction-scope.md))과 함께 적용한다.
