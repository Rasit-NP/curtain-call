# 진행 기록 (포트폴리오용)

프로젝트가 끝난 뒤 사람이 읽는 기록이다. Issue 하나에 파일 하나(`NNNN-제목.md`, NNNN은 Issue 번호)를 두고, 어떤 상황에서 무엇을 고민했고 어떤 근거로 골랐으며 결과가 어땠는지 시간 순서로 남긴다.

- 지금 유효한 결정만 빠르게 보려면 [`docs/decisions/`](../decisions/README.md)를 본다.
- 결함과 수정은 한 줄씩 [`docs/agent-log.md`](../agent-log.md)에도 있다.

## 쓰는 법

- Issue 작업을 시작하면 파일을 만들고, PR마다 그때그때 갱신한다. 끝난 뒤 몰아서 쓰지 않는다.
- 항목: 기간, Issue·PR, 관련 결정, 배경, 판단과 근거(사람이 정한 것과 에이전트가 정한 것을 구분), 실패와 수정, 리뷰, 결과, 배운 점.
- 대화에서 사람이 정하거나 바로잡은 것도 적는다.
- 목차와 파일이 어긋나면 `verify.sh harness`가 실패한다.
